# SPIKE Asset Provenance Evidence

Store evidence here for every asset whose ownership/license is not self-evident.

Recommended files:

- `icon.png.txt`
- `badges.txt`
- `incoming.mp3.txt`
- `notifications.mp3.txt`
- `outgoing.mp3.txt`
- `me.jpg.txt`

Each record should state:

- creator/source
- date obtained/created
- tool/service used (if applicable)
- license/permission
- commercial-use status
- source URL
- evidence filename(s)
- SHA-256 hash
